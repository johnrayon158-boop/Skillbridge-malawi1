# Competency evidence graph

The student evidence graph provides a visual summary of perceived skill confidence across the current profile. It is intentionally simple, transparent, and driven by platform data.

## Displayed fields
- Skill name
- Trust score
- Evidence count
- Source types such as assessment, portfolio project, certificate and experience

## Data flow
The graph aggregates profile skills, assessment results, projects, certificates and portfolio records. Each skill is then scored according to how many real evidence sources support it.

## User value
This helps the student understand where they are strongest, which skills need more evidence, and which competencies should be targeted next.
