# Career decision simulator

The simulation page compares multiple career paths based on the candidate's current evidence, current profile and projected improvements.

## Core approach
- Sort the available career options by likely fit
- Estimate a current score from the profile and existing skill coverage
- Model a projected improvement scenario such as more evidence, confidence or project delivery
- Show the likely before and after fit for each route

## Outcome
The simulator is not a promise of employment outcome. It is a structured planning tool that helps a student decide which learning and evidence activities are worth prioritizing.
