# Evidence trust and verification

Evidence trust is a normalized score that estimates how strongly a skill is supported by real student artifacts.

## Sources counted
- Assessment score
- Portfolio project evidence
- Certificates and credentials
- Experience-based signals
- Employer feedback where present

## Scoring logic
Each source contributes a weighted value based on its evidence type and recency. A skill with only one weak signal will remain low-confidence, while a skill supported by assessments, project work and verified credentials will rank as highly verified.

## Why this matters
The platform uses this signal to explain confidence in the recommendation engine and to support interview preparation and job-readiness guidance without exposing a false certainty level.
